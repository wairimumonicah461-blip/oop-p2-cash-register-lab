# Cash Register

A simple Python program that models a cash register for an e-commerce site.

## What it does

- Creates a cash register with an optional discount (a whole number from 0 to 100)
- Adds items with a price and an optional quantity
- Applies the discount to the total
- Voids the last transaction

## How to run

1. Clone this repo
2. Run `pytest` in the project folder to run the tests

## Files

- `cash_register.py` has the `CashRegister` class
- `testing/` has the tests
